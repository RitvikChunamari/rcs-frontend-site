# Adaptive direction upgrade

The existing black Swiss identity, Geist font, comparison, navigation and installation flow remain the basis of this release. Audience: developers selecting a design workflow for coding agents. The added content should explain user-supplied direction, coherent combinations and contextual choice before describing testing and critique.

Acceptance criteria:
- Three direction paths are explicit and grounded in audience/task/content.
- Unit/component testing, test-driven behavior changes, design contracts, critique/repair, continuity, interaction recovery and evidence reporting are described.
- No comparison-skill names appear in product copy or metadata.
- Existing menu, slider and copy command still work.
- Text reflows at 320, 375, 768, 1024 and 1440px.

Changes: updated hero summary and workflow copy; added three compact direction explanations alongside the atlas; expanded the existing standards section into six upgrade descriptions. The earlier comparison is identified as an earlier study and is not presented as a benchmark of this release.

Rendered critique: inspected desktop direction/features and mobile direction/features screenshots. Hierarchy and spacing follow the existing grid, with no observed clipping or overflow. No new visual defect requiring a corrective design pass was identified.

Verification: production build, whitespace check, responsive document-overflow checks at all five widths, menu/Escape, comparison presets and keyboard adjustment, clipboard contents, reduced-motion browsing, source design audit. Axe-core 4.10.3 scans returned zero violations in both themes; ARIA/contrast incomplete checks require manual assessment. Cross-browser, real-device, screen-reader and field performance measurements were not run.

This page describes the instruction package's workflows. Agent compliance across models and end-to-end design improvements remain to be evaluated with the bundled scenario specifications.
