# Creative Direction — RC's Frontend Skill

## Thesis
For builders using AI coding agents, this site should feel like switching on a complete design studio because the skill coordinates research, design, engineering, and QA as one workflow, expressed through a tactile before/after instrument and a kinetic Swiss system without obscuring installation or evidence.

## Direction choice
- Chosen: Kinetic Swiss + tactile utility. Clear structure gives the broad capability set credibility; the comparison handle makes transformation physical and memorable.
- Rejected: ambient AI aurora. Too generic for a skill that explicitly resists generic output.
- Rejected: faux creative-software desktop. Risks imitating system UI and making installation harder to scan.

## Grammar
- Grid: 12-column editorial field; full-bleed transformations; compact 4-column mobile reflow.
- Type: system grotesk for structure, Georgia italic for human direction, monospace for evidence and commands.
- Palette: ink, warm paper, signal chartreuse, transformation violet, proof coral.
- Motif: hinged brackets, crop marks, studio index labels, a live vertical transformation seam.
- Motion: one hero orbital mark, scroll-tied CSS reveals, draggable comparison. Reduced motion preserves every state without movement.
- Signature moment: the real Threadline before/after builds occupy the same frame and are revealed with a range control.

## Interaction contract
- Comparison is a native range input with keyboard, touch, and pointer behavior.
- Before/After buttons set explicit states and expose pressed state.
- Iframes are display-only and removed from the accessibility tree; textual labels and instructions describe the comparison.
- Navigation and GitHub/install links remain ordinary anchors.
