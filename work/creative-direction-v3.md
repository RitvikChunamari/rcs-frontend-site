# RC's Frontend Site — Creative Direction V3

## Thesis

For builders evaluating an agent design skill, the site should feel like a precise design operating system because the product combines research, visual direction, engineering, and verification, expressed through a Swiss editorial instrument with a single acid signal color, without compromising install and repository access.

## Style decision record

- Audience and jobs: AI-assisted builders; understand the scope, inspect proof, install the skill.
- Brand attributes: exact, original, accountable.
- Primary style: Swiss editorial, for clarity, hierarchy, and a credible design-practice voice.
- Secondary influence: kinetic utility, limited to the hero system panel and concise hover feedback.
- Rejected: glass/aurora because it weakens precision; 3D spectacle because it distracts from proof and adds runtime cost.
- Composition: asymmetric 12-column desktop rhythm; single-column mobile reading order; one full-width proof ribbon.
- Typography: sans-led, oversized but bounded display; mono metadata; no decorative serif dependency.
- Palette: warm paper, carbon ink, acid signal, cobalt proof section; semantic light/dark modes.
- Material: flat editorial planes, hairline rules, small technical radii; no stacked soft-shadow cards.
- Motion: one slow hero instrument drift and immediate control feedback; disabled under reduced motion.
- Memorable moment: the hero reads as a live studio system with six disciplines orbiting one bold identity mark.
- Protected behavior: comparison slider, navigation anchors, mobile menu, theme toggle, GitHub links, and embedded before/after builds.

## Verification targets

- No horizontal overflow at 320, 375, 768, 1024, and 1440 px.
- Keyboard-operable menu, theme, comparison, copy control, and links.
- Visible focus and at least 44 px touch controls.
- Reduced motion retains all content and state feedback.
- Light and dark modes retain readable contrast.
